# Employee Management System

A mini project developed using **Java Servlets and JDBC** to manage employee information through a web-based application.

## 📌 About the Project

The Employee Management System is a Java web application designed to simplify the management of employee records. It uses Java Servlets to handle client requests and JDBC (Java Database Connectivity) to interact with the database.

This project demonstrates the practical implementation of Java web development concepts, database connectivity, and server-side request processing.

## 🚀 Features

- Add new employee records.
- View employee details.
- Update existing employee information.
- Delete employee records.
- Store and retrieve employee data using a database.
- Handle user requests using Java Servlets.

## 🛠️ Technologies Used

- **Java** – Core application logic
- **Java Servlets** – Server-side request handling
- **JDBC** – Database connectivity
- **PostgreSQL** – Database management
- **HTML/CSS** – User interface 
- **Apache Tomcat** – Servlet container

## ⚙️ Prerequisites

Before running the project, make sure you have:

- Java Development Kit (JDK)
- Apache Tomcat
- PostgreSQL
- JDBC driver for your database
- An IDE such as Eclipse or IntelliJ IDEA

## 🎯 Learning Objectives

This project helped me practice:

- Java Servlet lifecycle and request handling.
- JDBC database connectivity.
- Executing SQL queries from Java.
- Integrating a Java web application with a relational database.
- Deploying servlet-based applications using Apache Tomcat.
